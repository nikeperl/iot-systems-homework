# OTA-обновление ESP8266

Скетч `esp8266_ota_update` проверяет версии прошивки и LittleFS при запуске и затем каждые пять минут. Сервер получает текущую версию в заголовке `x-esp8266-version`: при необходимости отдаёт бинарный файл, иначе отвечает `304`.

## Выбор сервера

| Папка | Возможности | Запуск |
| --- | --- | --- |
| `server/` | Прошивка (`/update`) и LittleFS (`/updateFS`) | `npm start` |
| `firmware-only-server/` | Только прошивка (`/update`) | `npm start` |

Оба сервера слушают порт `3000`; запускайте один вариант за раз. У обоих есть `GET /` и `GET /version`. Полный сервер нужен, если проверяете обновление файловой системы; вариант только с прошивкой отвечает `404` на запрос скетча к `/updateFS`.

## Подготовка скетча

1. В `esp8266_ota_update/` скопируйте `secrets.example.h` в `secrets.h` и заполните Wi-Fi.
2. Задайте IP компьютера с сервером в `OTA_SERVER_HOST`, порт — в `OTA_SERVER_PORT`.
3. Укажите текущую версию в `FIRMWARE_VERSION`.
4. Первую прошивку загрузите на ESP8266 через USB. Выберите разметку flash с местом для OTA и LittleFS, соответствующую вашей плате.

## Подготовка бинарных файлов

Бинарные файлы исключены из Git и собираются локально для выбранной платы.

- Экспортируйте скомпилированную прошивку в Arduino IDE и скопируйте её в `server/firmware/firmware.bin`. Оба варианта сервера читают один и тот же файл.
- Для полного сервера подготовьте образ LittleFS и положите его в `server/filesystem/filesystem.bin`. В образе должен быть `/version.txt` с версией файловой системы, например `1.0`. Создайте `data/version.txt` рядом со скетчем перед сборкой образа. Исходного образа с доступными для редактирования файлами в репозитории нет.
- Обновите `LATEST_FIRMWARE_VERSION` в выбранном `index.js`, а для полного сервера — также `LATEST_FILESYSTEM_VERSION`. Версии должны соответствовать содержимому бинарных файлов.

Пустые каталоги `firmware/` и `filesystem/` сохранены с помощью `.gitkeep`. Версии сравниваются через `parseFloat`: используйте формат `1.0`, `2.0`, `3.0`, а не сложные версии вида `1.2.3`.

## Запуск

Для полного сервера, из корня репозитория:

```bash
cd ota/server
npm ci
npm start
```

Для второго варианта выполните те же команды в `ota/firmware-only-server`.

Проверка из другого терминала:

```bash
curl http://localhost:3000/version
curl -I -H 'x-esp8266-version: 999.0' http://localhost:3000/update
```

Второй запрос должен вернуть `304`. Если версия устройства ниже серверной, а бинарного файла нет, сервер отвечает `404`. После подготовки образов подключите плату к той же сети и проверьте сообщения в Serial Monitor на скорости `115200`.
