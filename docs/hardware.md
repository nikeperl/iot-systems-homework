# Подключение компонентов

Значения взяты из скетчей. Обозначения D-пинов соответствуют NodeMCU; при другой плате ориентируйтесь на номера GPIO. У всех компонентов и платы должна быть общая земля GND.

| Проект | Компонент | GPIO | NodeMCU |
| --- | --- | --- | --- |
| № 2 | Встроенный светодиод, активный LOW | 2 | D4 |
| № 2 | Кнопка, INPUT_PULLUP, нажатие на GND | 0 | D3 / FLASH |
| № 3 | Линия данных DHT11 | 2 | D4 |
| № 4, обе платы | Красный светодиод | 14 | D5 |
| № 4, обе платы | Жёлтый светодиод | 12 | D6 |
| № 4, обе платы | Зелёный светодиод | 13 | D7 |
| № 4, ведущая | Кнопка, INPUT_PULLUP | 0 | D3 / FLASH |
| № 6, ведущая | Красный / жёлтый / зелёный | 14 / 12 / 13 | D5 / D6 / D7 |
| № 6, ведущая | Кнопка, INPUT_PULLUP | 0 | D3 / FLASH |
| № 6, ведомая | Красный / жёлтый / зелёный | 5 / 4 / 0 | D1 / D2 / D3 |
| № 10 | Линия данных DHT11 | 2 | D4 |
| № 10 | Управляющий вход реле, активный HIGH | 5 | D1 |
| № 10 | Кнопка конфигурации, INPUT_PULLUP | 0 | D3 / FLASH |

Ведущая и ведомая платы задания № 6 используют **разные пины светодиодов**. В заданиях со светофорами HIGH включает внешний светодиод; подключайте каждый через токоограничивающий резистор.

GPIO ESP8266 работают с логическими уровнями 3,3 В. Для демонстрации реле используйте низковольтную нагрузку. GPIO 0 и 2 участвуют в выборе режима загрузки, поэтому подключённые компоненты не должны мешать запуску платы.
