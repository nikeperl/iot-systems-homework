# VK-бот для управления устройствами через MQTT

Бот принимает команды администратора ВКонтакте, отправляет их в MQTT и возвращает состояния устройств. В меню доступны светодиод и метеостанция.

## Подготовка и запуск

Нужны сообщество ВКонтакте с включёнными сообщениями и Bots Long Poll API, токен сообщества и числовой ID пользователя-администратора.

Из корня репозитория:

```bash
cd integrations/vk-mqtt-bot
python3 -m venv .venv
source .venv/bin/activate
python -m pip install -r requirements.txt
cp .env.example .env
```

Заполните `VK_GROUP_TOKEN` и `ADMIN_VK_ID` в `.env`, затем:

```bash
set -a
source .env
set +a
python bot.py
```

Отправьте боту `меню` или `/start`. Бот принимает управляющие команды только от `ADMIN_VK_ID`. При запуске он отправляет администратору сообщение о готовности.

## Протокол

По умолчанию используются `broker.emqx.io:1883` и следующие топики:

| Топик | Назначение |
| --- | --- |
| `vk/led/command` | Команды `on`, `off`, `toggle`, `state` |
| `vk/led/state` | Ответ со состоянием светодиода |
| `vk/station/command` | `state`, `relay on`, `relay off`, `relay auto`, `mode heat`, `mode cool`, `set temp min 20` и аналогичные пороги `temp` / `hum`, `min` / `max` |
| `vk/station/notify` | Ответы и уведомления метеостанции |

**Скетч метеостанции № 10 использует другой протокол** (`weather/station/...`). Для работы с этим ботом требуется прошивка с топиками `vk/...` либо отдельный MQTT-мост. Такой прошивки и моста в исходных файлах нет; прямая совместимость с заданием № 10 не заявляется.

Адрес брокера и топики задаются в `bot.py`. Версия Paho MQTT 2.x нужна для используемого `CallbackAPIVersion.VERSION1`.
